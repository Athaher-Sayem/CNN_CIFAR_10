# Pixels to Patterns — design-only showcase

Standalone, frontend-only visual field guide for the [CNN_CIFAR_10 notebook](https://github.com/Athaher-Sayem/CNN_CIFAR_10). Open `index.html` directly or serve this directory with `python -m http.server 8000` and visit `http://localhost:8000/`.

No original source, dependencies, or configuration are changed. The illustration is conceptual; it is not a prediction interface. The loss values and **74.65%** accuracy are from the notebook's saved output. The README separately reports **74.71%**; this prototype deliberately does not reconcile or claim a new benchmark.

## Design direction

Editorial research field note: warm paper, ink, coral annotations, slate-blue technical drawings. Instrument Serif + DM Sans + IBM Plex Mono, with system fallbacks. All design tokens live in `styles.css`. The page requires no runtime dependencies; web fonts are optional.
